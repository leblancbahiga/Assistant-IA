## Résumé exécutif

NURU V12 a absorbé V13-A/B (PersonaEngine, PrivacyLayer, SleepCycle, ModelRouter, CostGuard) et se positionne comme **Personal Cognitive Operating System**. La phase d'absorption est réussie sur le papier (commit `e6aceb8`). En code réel, on observe une dette accumulée sur 12+ versions qui crée **5 classes de risques** majeures :

1. **Sécurité** : PromptGuard + Keychain OK, mais aucune couverture contre RAG injection / path traversal / data poisoning en production (uniquement tests).
2. **Tests cassés en silence** : 3 fichiers de tests V10.3 et V4.5 importent des modules **`supprimés mais référencés`** (compresseur, citations, retrieval, viewmodels). Personne ne s'en est aperçu.
3. **Code health** : doublons (deux fichiers de logging), fichiers orphelins archivés mais non gitignored, `tests/__pycache__` non nettoyés (`conftest.py` à valider).
4. **Architecture ramifiée** : 135 .py, 4 sous-dossiers `routing/`, `orchestration/`, `core/`, `rag/`, `routing/` + doublons legacy (`memory_store.py` vs `memory/` package vs `long_term_memory.py` vs `memory_bridge.py`).
5. **RAM/seuils** : Politique RAM centralisée V10.3k ✅ (excellente initiative), mais `Orchestrator.pipeline_offline` échoue en test depuis 6 jours sans fix.

**Verdict** : NURU n'est pas distribuable, mais les **fondations sont correctes**. Les 5 P0 listés en fin sont traçables, mutuellement exclusifs, et **réparables en <2 jours**.

### 🔴 F-02 [P0 — BLOQUANT] `test_ram_monitor.py` et `test_reranker_seuil.py` collectent 0 items

**Preuve** :
```
tests/test_ram_monitor.py  → collected 0 items
tests/test_reranker_seuil.py  → collected 0 items
```

Ces tests sont des **scripts async sans `@pytest.mark.asyncio`** ni `async def test_*`. Depuis l'ajout de `asyncio: mode=Mode.STRICT` dans `pyproject.toml`, pytest rejette les `async def` au top-level. Conséquence : **les tests RAM et Reranker sont MORT-VIVANT**, ils s'exécutent en 0 items OK.

**Risque** : aucun filet de sécurité sur :
- Le déchargement modèles quand RAM < 500 MB
- Le seuil reranker 0.60 vs 0.40 vs 0.30

**Fix** : ajouter `@pytest.mark.asyncio` + renommer `async def test_*` ou convertir en `asyncio.run(...)` dans une fonction sync. 15 min/test.

### 🟠 F-04 [P1] Routage 2-pass et config — incohérences mineures

`config/settings.yaml` dit `hybrid_mode: cloud_first` mais `config.local_model_fallback` n'est jamais utilisé par `Router` (qui ne lit que `local_model`). Vérification :

```yaml
# settings.yaml ligne 9
hybrid_mode: cloud_first  # → Router.__init__(hybrid_mode='local_only') par défaut
```

Si `cloud_first` est activé, **chaque requête devrait aller au cloud** sauf si RAG local a un bon score. C'est le comportement `LOCAL_RAG_CLOUD` (Archon). Mais le test `test_*` ne le valide pas, donc **silence sur la sémantique réelle**.

**Fix** :
1. Documenter précisément les 4 modes dans `README.md`.
2. Ajouter un test end-to-end : `hybrid_mode='cloud_first'` doit router 80% vers le cloud.

**Effort** : 1h.

## 4. Recommandations architecture senior (V12+)

### 4.1 Refactoring `SYSTEM_PROMPT_STATIC`

```python
# Actuel (ligne 35-97 nuru_core.py)
SYSTEM_PROMPT_STATIC = """Tu es NURU V8+...
Ton utilisateur : Leblanc BAHIGA Mudarhi ..."""

# Cible
from src.identity_manager import IdentityManager
identity = IdentityManager.load()  # ~/.nuru/identity.yaml non versionné
prompt = SYSTEM_PROMPT_TEMPLATE.format(
    user_name=identity.name,
    user_role=identity.role,
    ...
)
```

### 4.2 Convention "shadow mode" pour absorptions futures

Quand V13-A/B est absorbé dans V12, créer explicitement :
1. `_archive/v13_<date>/` archivé et gitignored
2. Memo `references/absorption_v13ab.md` qui liste les features absorbées + tests désactivés
3. **CHECKLIST** : "tous les tests qui référençaient les modules archivés ont été supprimés ou migrés"

### 4.3 Tag "stale tests" obligatoire

Tout fichier `tests/test_*` qui finit avec `pytest --collect-only -q | grep "0 items"` doit déclencher un warning CI. Implémentable en 5 lignes :

```python
# conftest.py - ajouté
def pytest_collection_finish(session):
    if session.config.option.collectonly:
        return
    empty = [item.fspath for item in session.items if ...]  # détection plus fine
    if empty:
        print(f"⚠️  {len(empty)} fichiers de tests ne collectent aucun item")
```

### 4.4 Router : mode hybride réellement respecté

`hybrid_mode='cloud_first'` (settings.yaml) doit être lu PAR le constructeur. Aujourd'hui :

```python
# src/nuru_core.py ligne 110-111
self.router = Router(rag_engine=self.rag, is_online_check=self._is_online,
                    cloud_llm=self.cloud_llm)  # ← `hybrid_mode` jamais passé
```

→ Fix : `Router(..., hybrid_mode=config.hybrid_mode)`. 2 lignes.
